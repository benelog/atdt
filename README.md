# 갈무리 보관소 | 이야기 5.3 화면으로 보는 PC통신 갈무리 글

1994~1997년 PC통신(하이텔·천리안·나우누리)에서 갈무리해 둔 글 78편을,
옛 통신 프로그램 **이야기 5.3**(큰사람, 1992)의 화면처럼 보여주는 정적 웹사이트입니다.
모뎀으로 전화를 걸어 BBS "갈무리 보관소"에 접속하고, 게시판을 골라 글을 읽는 흐름을 흉내 냅니다.

**사이트: <https://atdt.benelog.net>** (GitHub Pages, `main` 브랜치 루트에서 배포. `CNAME` 파일이 도메인)

## 여는 법

```bash
python3 -m http.server                # http://localhost:8000
```

`index.html` 을 브라우저에서 바로 열어도 됩니다(모든 스크립트가 일반 script 라 file:// 로도 동작).

- 시작하면 도스 화면 → 이야기 시작 화면 → 통신 화면(모뎀 `ATZ`/`OK`) → 전화 걸기 창이 차례로 나옵니다.
- 전화번호부에서 **갈무리 보관소(555-1996)** 에 걸면 접속됩니다. `ATDT 5551996` 을 직접 쳐도 됩니다.
- 접속음은 Web Audio로 합성하며 전체 접속 과정은 7.5초입니다. 2초간 '쏴' 하고 커지는 소리로 마무리합니다.
  다이얼 뒤 짧은 '띠', 장2도 높은 '디~', 잠깐의 간격, '쏴~' 순서로 이어집니다.
  변조된 반송파로 모뎀의 데이터음을 흉내 냅니다. 녹음 파일은 사용하지 않습니다.
  접속 중 글쇠를 누르면 소리와 접속 시도를 함께 취소합니다. 소리를 끄면 같은 시간 동안 조용히 기다립니다.
  글 주소로 바로 들어올 때는 접속음을 건너뜁니다.
- BBS 명령: 게시판 번호(1~8), 전체 목록(9), 글 번호(1~78), `N`/`P` 쪽 넘김, `L` 목록, `T` 처음,
  `S 낱말` 찾기, `H` 도움말, `X` 접속 끝. 화면의 밝은 글자는 마우스로 눌러도 됩니다.
- 이야기 글쇠: `F10` 메뉴, `F1` 도움말, `F2` 한글 종류(조합형으로 바꾸면 글이 깨져 보임), `F5` 챙긴글 보기,
  `PgDn` 읽는 글 내려받기, `Alt-V` 파일 편집(읽기 전용 편집기), `Alt-L` 갈무리, `Alt-D` 전화 걸기,
  `Ctrl-F9` 전화 끊기, `Alt-Z` 색깔, `Alt-A` 화면 바꿈, `Alt-1` 선로 속도, `Alt-W` 환경 저장,
  `Alt-S` 나들이(도스), `Alt-X` 끝내기. 출력 중에 Enter/Space 를 누르면 나머지를 한꺼번에 찍습니다.
- 터치 기기나 세로 화면에서는 아래에 회색 소프트 키(전화번호부/전화 끊기, 처음 T, 목록 L, 이전 B, 다음 N, 찾기 S, 접속 끝 X, 자판)가
  나옵니다. 전화번호부가 열려 있는 동안에는 '전화 걸기' 키가 함께 나와 고른 곳으로 바로 접속합니다.
  접속 전에는 BBS 명령 키가 흐리게 보이고, 손가락 두 개로 벌려 화면을 확대할 수 있습니다.
- 시작 화면과 접속 전 화면에는 16색 사무실 배경이 나오고, 접속하면 파란 통신 화면으로 바뀝니다.
  가로세로 비율(4:3)을 유지하면서 위아래의 얇은 검은 여백과 소프트 키를 제외한 화면을 최대한 채웁니다.
- **글마다 주소가 있습니다.** 글을 읽으면 주소창이 `index.html#WHI` 처럼 바뀝니다(`#` 뒤는 그 글의 갈무리 파일 이름,
  글 끝에도 찍힘). 이 주소로 들어오면 도스 부팅과 전화 걸기를 건너뛰고 바로 접속해 그 글을 보여 줍니다.
  게시판은 `#b7`, 전체 목록은 `#all`, 글 번호 `#47` 도 됩니다(번호는 글을 지우면 밀리므로 나눠 줄 때는 파일 이름 쪽을).
  뒤로/앞으로 가기로 읽던 글 사이를 오갈 수 있습니다.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `posts/*.txt` | 갈무리한 글 원문(UTF-8). 파일 이름이 글 제목이다(아래 참고). |
| `build.py` | `posts/*.txt` 를 읽어 `js/posts.js` 를 만든다. 게시판 분류(`BOARDS`), 원본 CAP 파일 이름과 갈무리한 날(`CAPS`), 제외 목록(`EXCLUDE`)이 들어 있다. |
| `js/posts.js` | 생성 파일. `window.ATDT_DATA = {boards, posts}` |
| `js/term.js` | 80×29 터미널 엔진. 선로 속도에 맞춘 출력, ANSI 색, 챙긴글(스크롤백), 갈무리, 조합형 깨짐 흉내 |
| `js/host.js` | 모뎀(AT 명령, 전화 소리), BBS "갈무리 보관소", 도스 흉내 |
| `js/app.js` | 화면 모드, 글쇠, 풀다운 메뉴, 대화상자, 상태줄, 문서 편집기, 시작 화면 |
| `css/iyagi.css` | 이야기 5.3 모양을 CSS 로 새로 그린 것 |
| `assets/office.svg` | 책상·모니터·수납장·화분을 16색으로 새로 그린 시작 배경 |
| `assets/og-image.png` | Facebook 등 링크 공유용 대표 이미지 (1731×909 PNG) |
| `assets/og-image.prompt.txt` | 대표 이미지 생성에 사용한 프롬프트 |
| `fonts/neodgm.woff2` | Neo둥근모 글꼴 |

글을 더하거나 고치면 `build.py` 를 다시 돌립니다.

```bash
python3 build.py
```

새 txt 는 `BOARDS` 에 게시판을 정해 주어야 빌드가 됩니다. 이름과 수험번호가 있는
`posts/연세대 수험번호 성명 명단.txt` 는 개인정보라 `EXCLUDE` 로 빼 두었습니다.

### 링크 공유 이미지

`index.html`에 [Open Graph](https://ogp.me/) 메타태그를 두어 Facebook이 대표 이미지와 제목을 읽도록 했습니다.
이미지는 사이트 시작 화면을 참고해 내장 이미지 생성 도구로 만들었습니다.
글 주소는 `#`로 구분하므로 모든 글이 사이트의 공통 대표 이미지를 사용합니다.
배포 후에도 예전 미리보기가 나오면 [Facebook 공유 디버거](https://developers.facebook.com/tools/debug/)에서
사이트 주소를 다시 스크랩합니다.

### 파일 이름과 게시물 정보

갈무리 원문 머리에 당시 게시물 정보가 남아 있는 글(78편 중 63편)은 그 **제목이 곧 파일 이름**이고,
화면에서도 머리글을 원문 그대로 보여 줍니다(글 번호만 이 보관소의 번호로 바뀜).

```
 [53] 제목 : [위스키]With Pakistani
 올린이 : whisky00(이소영  )    96/08/06 02:08    읽음 :  21  관련자료 없음
```

`build.py` 가 알아보는 머리글은 하이텔식(`[번호] 제목 :` / `올린이 :`·`올린시각 :`), 나우누리·천리안 목록식
(`이름 (아이디)` / `제목  월/일 시:분  N line`), 천리안 `제목 :`/`보낸이:`, 하나로 `송신인:`/`제 목:`,
뉴스(`뉴스제공시각 :`/`제목 :`, 출처가 올린이 자리에 감)입니다. 파일 이름에 못 쓰는 글자
`/ : ? " < > | * \` 는 전각 글자(／ ： ？ ＂ ＜ ＞ ｜ ＊ ＼)로 바꾸고 잇단 공백은 하나로 줄입니다.
파일 이름이 머리글 제목과 다르면 `build.py` 가 고칠 이름을 알려 주고 멈춥니다.
한 CAP 파일에 여러 편을 이어 갈무리한 것(강좌 #1~#4 등)은 게시물마다 한 txt 로 나누어 두었습니다.
나뉜 글의 갈무리 파일 이름(`CAPS`)은 첫 편만 원래 이름이고 나머지는 `DEBUG-2.CAP` 처럼 번호를 붙였습니다
(글 주소로 쓰므로 서로 달라야 함). 인용이나 되풀이된 화면이 섞인 글은 한 편으로 둡니다.

머리글이 없는 글(아스키 아트, 소설 모음 등 9편)은 설명식 파일 이름이 제목이고, `제 목 :` 줄만 있는 글
(`[9503](1)32비트 보호 모드 프로그래밍` 등 6편)은 그 줄의 제목을 파일 이름으로 씁니다.

## 저작권과 출처

- 이 사이트는 이야기 5.3 의 **화면 모습을 본떠 새로 만든 재현물**이며 큰사람과 관계가 없습니다.
  원본 프로그램의 실행 파일, 비트맵 글꼴, 그림(시작 화면의 사무실 그림 등)은 쓰지 않았고
  모든 화면은 HTML/CSS/SVG 로 새로 그렸습니다.
  `../old-com/I/II.EXE`를 DOSBox에서 실행한 기본 VGA(640×480) 화면을 참고해 시작창,
  메뉴 간격, 전화번호부 위치와 상태줄을 맞췄습니다. 원본 `I.BAT`의 `/8` 옵션(800×600)은 재현하지 않습니다.
- 글꼴 **Neo둥근모**(Dalgona, v1.601)는 김중태 님의 둥근모꼴을 바탕으로 만든 글꼴로
  SIL Open Font License 1.1 을 따릅니다. 라이선스 전문은 `fonts/neodgm-OFL.txt` 에 있습니다.
- 갈무리한 글의 저작권은 각 글을 쓴 사람에게 있습니다. 신문 기사, 노래 가사, 단편 소설처럼
  저작권자가 따로 있는 글이 섞여 있으니 공개 배포 전에 살펴보십시오.

텍스트 모드에서의 비디오 메모리 번지 세그먼트는 흑백의  경우
(hgc,mda?) 16진수로 b000,즉 &hb000, 칼라의 경우(cga,ega,vga)
&b800입니다. 그리고 구성은 다음과 같습니다.

 adress     내용
    0       x:1,y:1의 글자 ascii코드
    1       x:1,y:1의 글자 속성
    2       x:2,y:1의 글자 ascii코드
        .
        .
        .
    160     x:1,y:2의 글자 ascii코드
    161     x:1,y:2의 글자 속성
        .
        .
        .
    3998    x:80,y:25의 글자 ascii코드
    3999    x:80,y:25의 글자 속성

이렇게 입니다. 여기서 속성은..
속성=배경색*16+글자색
이렇게 할수 있습니다.
예로 정해진 위치에 한 글자를 쓰는 서브를 만들면

SUB PUTCHAR(Y,X,CH$)
 DEF SEG=&HB800 ' 흑백은 &HB000
 POKE ((Y-1)*80+(X-1))*2,ASC(CH$)
END SUB

이렇게이고, 정해진 위치에 속성까지 쓰는 것으로 바꾸면..

SUB PUTCHAR2(Y,X,CH$,AT)
 DEF SEG=&HB800 ' 흑백은 &HB000
 POKE ((Y-1)*80+(X-1))*2,ASC(CH$)
 POKE ((Y-1)*80+(X-1))*2+1,AT
END SUB

이렇게 입니다.
반대로 PEEK를 이용하여 값을 읽을 수도 있습니다.
즉, 맨 위의 PUTCHAR을 글자를 읽는 것으로 바꾸면..

FUNCTION GETCHAR(Y,X)
 DEF SEG=&HB800 ' 흑백은 &HB000
 GETCHAR=PEEK(((Y-1)*80+(X-1))*2)
END FUNCTION

이렇게 할수 있습니다.
화면의 부분을 저장하는 간단한 서브를 만들어보죠..
베이직이라 느리지만, 이것을 C등으로 짜면 엄청 빠릅니다.
이 서브는 Y1,X1 - Y2,X2의 텍스트 화면을 저장하는 서브로
형식은

RESS RESS 좌상단Y좌표,좌상단X좌표,우하단Y좌표,우하단X좌표,세
그먼트

와

RESS WRSS 좌상단Y좌표,좌상단X좌표,우하단Y좌표,우하단X좌표,세
그먼트

로 합니다. 이때, 세그먼트는 흑백=&HB000,칼라=&HB800입니다.

DIM SHARED SB(4096) AS INTEGER

SUB RESS (Y1, X1, Y2, X2, SE)
 DEF SEG = SE
 NN = 0: FOR I = MMR(X1, Y1) TO MMR(X2, Y2)
 SB(NN) = CHR$(PEEK(I)): NN = NN + 1: NEXT
END SUB

SUB WRSS (Y1, X1, Y2, X2, SE)
 DEF SEG = SE
 NN = 0: FOR I = MMR(X1, Y1) TO MMR(X2, Y2)
 POKE I, ASC(SB(NN)): NN = NN + 1: NEXT
END SUB

FUNCTION MMR (X, Y)
MMR = ((Y - 1) * 80 + (X - 1) * 80) * 2
END FUNCTION

이렇게 입니다.
여기서 MMR은 X,Y 좌표의 번지(ADRESS)를 구하는 함수입니다.

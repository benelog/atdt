이렇게 구성되어있습니다.

-----------------------
페이지       범위
-----------------------
   0      0~15999
   1      16000~31999

   3      48000~63999
-----------------------

-----------------------
페이지       범위 쓸수 있지 않을까 싶네요.
이 서브들은 사이비모드로 초기화, 사이비 평면  모드에서의  점
읽기와 쓰기를 하는 서브입니다.

SUB SET4PLANEMODE
 SCREEN 13
 OUT &H3C4,&H4
 OUT &H3C5,&H6
 OUT &H3D4,&H14
 OUT &H3D5,&H0
 OUT &H3D4,&H17
 OUT &H3D4,&HE3
END SUB

SUB SETPIXEL(X,Y,C)
 OUT &H3C4,2
 OUT &H3C5,2^(X MOD 4)
 DEF SEG=&HA000
 POKE Y*80+(X\4),C
 DEF SEG
END SUB

FUNCTION GETPIXEL(X,Y)
 OUT &H3CE,4
 OUT &H3CF,(X MOD 4)
 DEF SEG=&HA000
 GETPIXEL=PEEK(Y*80+(X\4),C)
 DEF SEG
END SUB

SUB CLEARSCREEN(P)
 DEF SEG=&HA000
 OUT &H3C4,2
 OUT &H3C5,15
 FOR I=P*16000 TO P*16000+15999
  POKE I,0
 NEXT I
 DEF SEG
END SUB

이렇게입니다.
이제 여기서의 시작번지조작에 대해 알아봅시다.

시작번지란 현재 나오고 있는 화면의 가장 좌상단(0,0)의 메모리
번지입니다. 처음에는 0이기 때문에 메모리번지 0~16000까지  화
면에 나타나게 됩니다.
이 시작번지를 16000으로 하면 페이지 1이 시작되는 메모리 번지
이므로, 화면에 페이지 1의 내용이 나오게 됩니다.
그리고 48000으로 하면 페이지 3의 내용이 나오고..64000으로 하
면 어떻게 될까요? 화면에 64000~65535까지의 내용이 나오고  그
이하는 깨져서 나옵니다.
이 시작번지를 8000으로 하면? 그럼 페이지 0의 중간부터 페이지
1의 중간까지가 화면에 나타나게 됩니다.
사이비 모드에서는 시작번지를 320/4=80 , 80씩 조절해주므로써,
1도트 단위의 세로 스크롤이 가능해집니다.
가로 스크롤은 복잡하니, 여기서는 안 다루겠습니다.
처음 시작번지0에서 시작번지를 80으로 바꾸어주면 화면이 한 도
트 위로 스크롤 됩니다. 그러나, CPU에서는 좌표를 따질 때 스크
롤 되어진 좌표로 따집니다.
시작번지 조작은 다음과 같이 합니다.
A=시작번지   일때,

OUT &H3D4,&HC
OUT &H3D5,A \ 256
OUT &H3D4,&HD
OUT &H3D5,A MOD 256

이렇게 입니다.
참고로, 3D4,3D5는 CRT제어기 레지스터이며, 인덱스 &HC는  상위
시작 주소이고, 인덱스 &HD는 하위 시작 주소입니다.

그럼 위의 서브를 페이지도 되게 고쳐보죠.

DIM SHARED CURRENTAPAGE,CURRENTVPAGE

SUB SET4PLANEMODE
 SCREEN 13
 OUT &H3C4,&H4
 OUT &H3C5,&H6
 OUT &H3D4,&H14
 OUT &H3D5,&H0
 OUT &H3D4,&H17
 OUT &H3D4,&HE3
END SUB

SUB SETPIXEL(X,Y,C)
 OUT &H3C4,2
 OUT &H3C5,2^(X MOD 4)
 DEF SEG=&HA000
 POKE Y*80+(X\4)+CURRENTAPAGE*16000,C
 DEF SEG
END SUB

FUNCTION GETPIXEL(X,Y)
 OUT &H3CE,4
 OUT &H3CF,(X MOD 4)
 DEF SEG=&HA000
 GETPIXEL=PEEK(Y*80+(X\4)+CURRENTAPAGE*16000,C)
 DEF SEG
END SUB

SUB SETAPAGE(P)
 CURRENTAPAGE=P
END SUB

SUB SETVPAGE(P)
 CURRENTVPAGE=P
 SETSTARTADR P*16000
END SUB

SUB SETSTARTADR(N)
 OUT &H3D4,&HC
 OUT &H3D5,N\256
 OUT &H3D4,&HD
 OUT &H3D5,N MOD 256
END SUB

SUB CLEARSCREEN(P)
 DEF SEG=&HA000
 OUT &H3C4,2
 OUT &H3C5,15
 FOR I=P*16000 TO P*16000+15999
  POKE I,0
 NEXT I
 DEF SEG
END SUB

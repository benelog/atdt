==소브게임 라이브러리 강좌 1회==

안녕하세요?

소브는 여러가지 멋진 기능을 가지고 있으면서도

그럴싸한 설명서도 없고 제작자인 정세일(onlyBAB)님의

홍보도 부족해서 토우켄 보다도 못한 게임라이브러리가

되어 버렸습니다.하지만 알고보면 곳곳에 엄청난 기능

들이 숨어있어 사용자를 깜짝놀라게 하는데 이제부터

소브의 기능들을 설명드리겠습니다

=====1.스크린 명령어=====

1.PlaneMode (1.5버젼)

320x200,256 에서 4페이지를 쓸수 있는 플렌모드로 세팅해 줍니다.

일단 페이지를 이해하셔야 합니다.

4페이지라고 하면 모니터에 4장의 종이가 있다고 보시면 됩니다

단 종이의 뒷면은 사용할수 없죠

모니터로 한번에 볼수 있는것은 1페이지 뿐이고

실질적으로 작업을 할수 있는것도 1페이지 뿐입니다.

이해가 되셨나요?

페이지는 대부분 움직이는 캐릭터의 깜빡임을 없애기 위해 사용됩니다.

이건 뒤에서 설명하죠.

예제> '$INCLUDE:'SOB.BI'  <-  목록(없으면 소브사용 불가능)
      PlaneMode

2.PackedMode

320x200,256 팩모드로 세팅해 줍니다.

소브에서 아직 지원하는 명령이 없기 때문에 사용불가능이랍니다.

그렇기 때문에 설명을 넘어갑니다

3.TextMode

80x25 의 텍스트 모드로 세팅해줍니다.

PlaneMode 에서 텍스트로 돌아가고 싶을때 사용합니다.

예제> '$INCLUDE:'SOB.BI'
      PlaneMode
      TextMode

4.ViewPage 페이지넘버

4페이지중에서  모니터 상에 표시할 페이지를 고르는것입니다

1~4가 아니라 0~3 입니다.

초기값은 0페이지 입니다.

예제> '$INCLUDE:'SOB.BI'
      PlaneMode
      ViewPage 0
      TextMode

5.WorkPage 페이지넘버

4페이지중에서 작업할 페이지를 정하는 것입니다.

WorkPage 와 ViewPage 가 다르다면 WorkPage 에서 무슨일을 하던 화면에는

보이지 않습니다.

초기값은 0페이지 입니다.

예제> '$INCLUDE:"SOB.BI'
      PlaneMode
      ViewPage 0
      WorkPage 3
      TextMode

6.CopyPage 페이지넘버 1 , 페이지넘버 2

페이지넘버 1 의 내용을 페이지넘버 2 에 복사합니다

상당히 빠르고 캐릭터의 깜빡임을 없에기 위해 사용됩니다.

게임을 만들때 보통 캐릭터를 찍어낸후 캐릭터찍어낸곳에 배경을 다시 찍어내
고

이동한 캐릭터를 찍어냅니다

이와 같이 하면 캐릭터가 보기 싫게 깜빡이게 됩니다.

WorkPage 에서 이와 같은 과정을 모두 거친후 결과만을 ViewPage  에 복사한
다면

캐릭터의 깜빡임을 없엘수 있습니다.

예제> '$INCLUDE:'SOB.BI'
      PlaneMode
      ViewPage 0
      WorkPage 3
      CopyPage 3,0
      TextMode

7.SetClip 가로1,세로1,가로2,세로2

클립핑할 구역을 정합니다

SETCLIP 50,50,150,150 이라고 했을때

┌───┬────────┬─────┐
│      │                │          │
│   ⓑ │         ⓒ     │    ⓓ    │
│      │(50,50)         │          │
├───┼────────┼─────┤
│      │                │          │
│   ⓕ │       ⓐ       │    ⓔ    │
│      │                │(150,150) │
├───┼────────┼─────┤
│  ⓖ  │      ⓗ        │    ⓘ    │
└───┴────────┴─────┘

이렇게 클리핑에 정해집니다.

A,B,C,D,E,F,G,H,I 면에 똑같이 점을 찍었을때

A면에만 점이 찍히고 B,C,D,E,F,G,H,I 면에는 점이 찍히지 않습니다.

예제> '$INCLUDE:'SOB.BI'
       PlaneMode
       SetClip 60,10,180,180
       TextMode
